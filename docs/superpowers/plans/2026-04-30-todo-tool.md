# Todo Tool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为单 Agent 多工具循环新增 todo 管理能力，支持创建、更新、单一 in-progress 约束，以及连续多轮未使用 todo 时的提醒注入。

**Architecture:** 使用 `TodoManager` 作为 todo 状态唯一真相源，`TodoTool` 暴露给模型调用，`AgentLoopService` 负责新用户任务开始时重置 todo，并在单轮循环中根据工具调用情况注入 reminder。保持现有 `ToolRegistry` 和 `runTurn(history, query)` API 不变。

**Tech Stack:** Java 17, Spring Boot, Spring AI Tool annotations, JUnit 5, Mockito
